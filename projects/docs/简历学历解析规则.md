# 简历学历识别

## 规则

- 分别保存每段教育经历的学校、专业、学历和毕业时间，不因同校另一条经历更完整而丢弃硕士或博士记录。
- 本科兼容“学士”、Bachelor、B.Sc.、B.Eng.；硕士兼容 Master、M.Sc.、M.Eng.、MBA、EMBA；博士兼容 PhD、Ph.D.、Doctor of Philosophy、DPhil。
- 仅写“研究生”无法区分硕士与博士，保留待核对；“博士后”是经历而非学位，不单独据此推断博士。
- 文本 PDF 根据文字坐标恢复同一视觉行，再关联学校与右侧学历。已经错序的纯文本仅在学历列与学校可一一对应时按顺序补齐，歧义项不猜测。
- 院系不应被误当作另一所学校；课程、导师称号、工作经历和岗位学历要求不能提升候选人学历。
- AI 可以补充漏掉的教育经历，但学校和学历都需有教育章节原文证据，不接受模型无依据升级学历。

## 最高学历与展示

- 按博士、硕士、本科及其他学历等级计算最高值，不按数组顺序或最近毕业时间选择。
- 列表、详情及学历筛选使用一致的计算口径。教育经历已有硕士/博士时，不被旧的本科摘要遮盖；不会因档案只补录部分经历而丢失已人工填写的更高学历。
- 页面逐条展示学校、专业和学历标签；无明确学历时标记待核对。
- 保存教育经历时同步最高学历，并保留专业字段。

## 已有简历

进入候选人详情，在“简历附件”点击“重新解析”。结果进入维护表单，由 HR 核对后保存。解析本身不覆盖主档，也不批量重写历史数据。

例如北京大学“工科/硕士”和武汉大学“理科/学士”，应分别保存为硕士与本科，最高学历为硕士。
