# 工作台重组

## 布局与入口
工作台顶部展示待初筛、待安排面试、待面试反馈、待跟进审批、未读到期提醒。
前四类沿用 dashboard workbench_metrics 的统计值及目标路由，不在前端另算人数。
团队待办并非仅统计今天创建，也不意味着每项均需当前用户亲自处理；审批由 HR 跟进当前节点。
非 HR / 超级管理员账号不展示团队待办卡片，提供“我的任务”入口。

到期提醒仅查询当前登录账号的未读通知，包括 Offer 到期、审批到期、需求逾期、阶段提醒与阶段已到期。
通知数量与实时业务待办不同；完成业务不会在本轮自动标记通知已读。
新增 scene_group=deadline 通知筛选，并支持通过 URL 精确打开未读到期通知。
到期筛选视图禁止“全部已读”，避免一次标记其他类型通知；可逐条阅读。

保留候选人搜索与原阶段统计，将阶段统计放入可展开区域。
保留周日程，新增“回到本周”，点击日程定位具体面试记录。
统计刷新失败保留上次成功数据并提示；日程和通知分别提示错误与重试。
保持业务事件、窗口焦点、可见性及轮询刷新。
