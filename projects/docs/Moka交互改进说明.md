## 启动
按开发接续说明启动 MongoDB 与后端；前端进入 projects/frontend，执行 npm ci 后执行 npm run dev。
当前依赖已安装，可在本目录直接启动前端。复制到桌面时脚本会跳过依赖、虚拟环境和构建目录，需要重新安装依赖。
Windows 如找不到 npm，可使用 C:\Program Files\nodejs\npm.cmd。

## 复制到桌面
在自己的 PowerShell 中运行仓库根目录的 COPY_TO_DESKTOP.ps1。
脚本复制到桌面 tange-hr-moka-improvements，保留本地 Git；目标已存在会停止，不会覆盖。
当前受限环境不能直接写入桌面。
