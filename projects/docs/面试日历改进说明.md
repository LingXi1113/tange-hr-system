# 面试日历改进

## 使用
面试管理默认展示系统内周日历，可切换日视图及原有列表。
待约面、待反馈等工作台深链接仍默认进入对应列表。
页面上方状态、职位、轮次、处理状态及面试官查询条件沿用原接口，日历与列表切换保留当前筛选。
日期选择、上一/下一时段、今天及刷新均可用；日历按开始时间排列，并非按小时比例绘制的时间轴。
点击事件显示只读详情，再按原权限进入编辑、改期、评价或候选人详情。
未安排具体时间的应聘记录仍在列表处理，不作为虚假日程。
跨天事件显示在覆盖的各天；取消或归档事件灰显；同一面试官或候选人的有效面试重叠时提示。
前端重叠提示仅根据当前加载结果，不能代替服务端校验或企业完整日历。

## 服务端
日历请求 date_range_mode=overlap，按半开区间交集返回跨天事件。
新建、编辑、改期统一检查候选人或面试官是否占用重叠时间。
有效状态为 pending / invited / confirmed / rescheduled；已完成、已取消不参与冲突检查。
前一场结束等于下一场开始可衔接；更新和改期排除当前记录本身。
按候选人及面试官依次取得 MongoDB 短租约，面试官租约使用独立字符串键，防止不同候选人并发占用同一面试官。
保留原版本检查、评价与阶段流转规则。
日历分页取全当前范围，最多加载 1000 条；超出或中途失败显示错误，要求缩小范围，不静默只显示首页。
